## Selected Work

**AI Educational Assistant — Multi-Subject RAG Agent**
Production system for 500+ students across 5 subjects and 4 teachers. Answers strictly from curriculum material with page-level citations.
- Hybrid retrieval: semantic vector search + full-text search, fused with Reciprocal Rank Fusion
- LLM-based semantic chunking that keeps rules, examples and answers together
- Router agent for intent classification, main agent for grounded generation
- Multimodal input: OCR on exam photos, voice transcription

**AI Sales Agent — Lead Qualification & Booking**
Conversational agent for an EdTech academy that takes leads from first contact to a booked session.
- Configurable qualification flows and automatic lead classification
- Availability-aware, timezone-safe booking
- Human handover with generated conversation summaries

**Healthcare Customer Service Agent**
Autonomous appointment management for medical clinics, reducing manual workload by ~90%.
- Routing between booking, FAQ retrieval and human escalation
- Real-time integration with a custom CRM
